What this is

The port, concretely.

  • Native binary

    Launches from pi or pi-rust. Release builds are optimized; the installed command resolves directly to the Rust binary. No interpreter, no bundle, no version drift.

  • Provider auth works today

    /login openai-codex reaches the real browser OAuth URL and cancels cleanly. A stored Codex credential completed two print turns and two interactive PTY turns. Bracketed-pasted Qwen API keys are masked, persisted, and removable via /logout.

  • Compatibility where it counts

    Session formats, RPC messages, and transport behavior mirror upstream so existing sessions and integrations survive the port.

  • TUI under a 52-capability contract

    Every pane, keybinding, theme, and interaction is tracked against official Pi, including Kitty CSI-u input and Bash-completion regressions. Both are release-tested; the full workspace release suite is green.

  • Rust-only distribution

    Zero JS/TS executable source files in the shipped tree (generated Rustdoc excluded).
